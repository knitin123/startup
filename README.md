# Digital Mandi

Digital Mandi is a full-stack B2B agri-commerce platform designed to connect farmers, buyers, agents, and agricultural supply chains through technology.

## Vision

Build a digital mandi ecosystem where agricultural demand and supply can be discovered, verified, matched, and transacted digitally.

## Core Ecosystem

- Farmer
- Buyer
- Agent
- Admin

## Core Workflow

Buyer Requirement
↓
Demand Discovery
↓
Farmer / FPO Supply
↓
Agent Verification
↓
Demand-Supply Matching
↓
Offer / Negotiation
↓
Deal
↓
Quality Verification
↓
Logistics
↓
Payment
↓
Commission
